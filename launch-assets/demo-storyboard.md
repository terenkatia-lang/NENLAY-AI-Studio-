# Демонстраційний ролик до 60 секунд

## Формат
Вертикальний 9:16, 1080×1920, без музики з авторськими правами. Додати субтитри українською та watermark `NENLAY AI` у правому нижньому куті кожного кадру.

## Сценарій
1. **0–2 с — hook:** звичайне фото або порожній кадр. Текст: «Одне фото. Три ідеї для реклами».
2. **2–5 с — prompt:** швидкий screen recording вставки промту: `premium car campaign, cinematic light...`.
3. **5–10 с — result:** swipe до ефектного AI-візуалу авто з watermark. Текст: «Результат за хвилину».
4. **10–25 с — niches:** три короткі приклади: авто → нерухомість → дизайн. На кожному: назва ніші та CTA «Спробувати промт».
5. **25–42 с — tutorial:** показати структуру ідеального промту: об’єкт + стиль + світло + композиція + формат.
6. **42–52 с — referral:** «Зареєструйся та отримай 2 генерації. Запроси друга — +10 кредитів».
7. **52–60 с — CTA:** показати URL і кнопку «Спробувати безкоштовно». Озвучка: «Твоя наступна рекламна ідея — у NENLAY AI».

Не називати демонстраційні концепти клієнтськими кейсами. Після появи реальних робіт замінити їх на підтверджені кейси з дозволом клієнта.
